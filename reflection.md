# Reflection

Building this portfolio taught me the value of disciplined planning, iterative prompting, accessibility auditing, and production deployment with strict security headers. AI served as an effective drafting partner: it quickly scaffolded the initial semantic HTML structure, CSS layout tokens, and baseline JavaScript listeners, which I then critically reviewed, refined, and tested against my requirements.

My biggest challenge was diagnosing the subtle hover-lag bug, where persistent entrance transition classes delayed pointer reactions, and steering the design away from generic SaaS templates toward a distinctive Technical Mono aesthetic. I also had to balance strict Content Security Policy headers with smooth CSS-driven interactions. Moving forward, my next step is to expand my published projects on GitHub—diving deeper into distributed systems, network security protocols, and machine learning utilities—and showcase them here as my journey progresses.
