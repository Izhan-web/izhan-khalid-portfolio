# Izhan Khalid — Personal Portfolio

A modern, responsive personal portfolio website introducing my background, areas of interest, and selected projects.

Built as part of the **Looponics — Modern Web Development with AI** student practical challenge.

## Overview

This website serves as my personal portfolio, providing an overview of my background as a Computer Science student and my interests in development, artificial intelligence, and cybersecurity.

The design focuses on a clean visual hierarchy, modern aesthetics, responsive layouts, and subtle interactive elements.

## Features

- Responsive design for desktop, tablet, and mobile.
- Modern glassmorphism-inspired UI.
- Dark visual theme with an olive, burgundy, and burnt-orange color palette.
- Centered hero section.
- About section introducing my academic background and interests.
- Three areas of interest: Development, Artificial Intelligence, and Cybersecurity.
- Selected projects linked to GitHub.
- Functional navigation and contact links.
- Scroll-triggered animations.
- Responsive navigation and interactive hover effects.

## Technologies Used

- HTML5
- CSS3
- JavaScript



## Running Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/Izhan-web/izhan-khalid-portfolio.git
   ```

2. Open the project folder:

   ```bash
   cd izhan-khalid-portfolio
   ```

3. Open `index.html` in your browser.

   Alternatively, use the Live Server extension in Visual Studio Code if available.

   If your project uses a build tool, follow the scripts and instructions in `package.json` instead.
