# Izhan Khalid — Personal Portfolio

A modern, responsive personal portfolio website showcasing my background, areas of interest, and selected projects.

**Live Website:** [https://izhan-khalid-portfolio.vercel.app/](https://izhan-khalid-portfolio.vercel.app/)

## About

This website was created as part of the **Looponics — Modern Web Development with AI** student practical challenge.

## Features

- Responsive design for desktop, tablet, and mobile.
- Modern glassmorphism-inspired design.
- Dark theme with olive, burgundy, and burnt-orange accents.
- Personal introduction and areas of interest.
- Selected projects with GitHub links.
- Functional navigation and contact links.
- Scroll-triggered animations and interactive elements.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Git and GitHub
- Vercel
